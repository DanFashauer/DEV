# SignalGrid Integration Priorities

This document prioritizes integration work by pilot impact and implementation risk.

## Now (highest pilot value / lowest implementation risk)

1. **Intune** — core posture and compliance source for enterprise endpoint trust.
2. **Jamf** — critical for Apple-heavy shared-device environments.
3. **Entra ID** — foundational identity signal and enterprise access context.
4. **ServiceNow** — immediate operational bridge for incident/ticket workflows.
5. **SIEM/XDR connectors** — high-value for decision receipts, evidence, and SOC/IR visibility.

## Next (strong strategic expansion)

1. **Workspace ONE** — expands enterprise endpoint coverage.
2. **Okta** — broad IAM interoperability for mixed enterprise environments.
3. **NAC ecosystem depth** — stronger network-level enforcement consistency.
4. **HID / badge ecosystem** — higher confidence physical-to-digital trust continuity.
5. **ITSM templates/playbooks** — faster operationalization of decision outcomes.

## Later

1. **Mobile credential / wallet direction** — strategic extension for credential portability.
2. **Richer XDR-driven trust weighting** — improved context quality for policy decisions.
3. **Cross-provider trust normalization layer** — lower policy drift across heterogeneous stacks.

## Concept/research

- Unified credential trust model across identity provider, endpoint manager, and physical badge/mobile credential ecosystems.
- Adaptive integration scoring that weights signal quality by provider reliability and freshness.
