# SignalGrid Terminology

## Purpose
This file defines approved wording for SignalGrid demo and documentation.
Prevents wording drift across screens and ensures buyer-friendly language.

---

## Core Decision Terms

| Term | Approved Use | Avoid |
|------|--------------|-------|
| Access Granted | Session approved, user can use device | Allow, Approved, Accepted |
| Access Denied | Session blocked due to policy | Denied, Rejected, Blocked |
| Session | Device access session | Connection, Login, Session |

---

## Security Terms

| Term | Approved Use | Avoid |
|------|--------------|-------|
| Device Security Check | Checking device compliance posture | MDM Lookup, Posture Evaluation, Device Trust Check |
| Security Policy | Policy that controls access decisions | Policy Engine, Policy Evaluation, Rules |
| Automated Security Actions | Actions triggered by policy decisions | Policy Actions, Enforcement Actions |
| Device Compliant | Device meets security requirements | MDM Compliant, Enrolled, Managed |
| Device Non-Compliant | Device does not meet security requirements | Non-Compliant, Failed, Violated |

---

## User Terms

| Term | Approved Use | Avoid |
|------|--------------|-------|
| User | Person using the device | Actor, Principal, Identity |
| Role | User's job function | Persona, Department, Type |
| Badge | Physical access credential | Credential, Token, Key |
| Tap badge | Present badge to reader | Scan badge, Swipe, Authenticate |

## Return/Checkout Terms

| Term | Approved Use | Avoid |
|------|--------------|-------|
| Return to | Where device should be returned | Return Location, Home, Dock |
| Due back | When device should be returned | Due, Return Time, Expiration |
| Checked out to | Current user of device | Assigned to, Owned by, Current User |
| Overdue | Device not returned on time | Late, Expired, Past Due |
