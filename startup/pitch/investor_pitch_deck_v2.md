## Appendix: Demo Flow

### Healthcare Scenario: Shared iPad

```
1. Nurse approaches iPad
2. Taps badge (BLE)
3. SignalGrid authenticates:
   - Lookup badge → user
   - Check device posture (FleetDM)
   - Evaluate policies
4. Policy result:
   - ✅ Launch "Patient Check-In" app
   - ✅ 15-minute session
   - Log to SIEM
5. Nurse walks away (BLE disconnect)
6. Device auto-locks in 5 seconds
7. Session ends, audit logged
```
