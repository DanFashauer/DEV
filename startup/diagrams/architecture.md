## Scalability Characteristics

### Performance by Component

| Component | Scale | Notes |
|-----------|-------|-------|
| Admin Dashboard | 100s concurrent | Stateless, CDN cached |
| Session API | 10K req/sec | Redis-backed, horizontal |
| Policy Engine | In-memory | Sub-millisecond eval |
| MDM Integration | API rate limited | Per-vendor limits |
| ITSM Integration | Async queue | Retry with backoff |
| SIEM Export | Async, buffered | Non-blocking |
| Audit Ledger | Append-only | SHA-256 chain |
